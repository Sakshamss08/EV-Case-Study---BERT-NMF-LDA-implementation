# EV Customer Insights using BERTopic, LDA & NMF

## Overview

This project analyzes Electric Vehicle (EV) customer reviews using Natural Language Processing (NLP) and Topic Modeling techniques to identify key customer concerns, preferences, and emerging trends.

Three topic modeling approaches are implemented and compared:

- BERTopic (Transformer-based)
- Latent Dirichlet Allocation (LDA)
- Non-negative Matrix Factorization (NMF)

The project follows an end-to-end NLP pipeline including text preprocessing, topic extraction, visualization, sentiment analysis, and business insights.

---

## Objectives

- Extract meaningful topics from EV customer reviews.
- Compare BERTopic, LDA, and NMF.
- Identify customer pain points and positive experiences.
- Generate actionable business recommendations.
- Build a scalable NLP pipeline for customer intelligence.
